 MyAcademy

A modern frontend web application built using Next.js and TypeScript, focused on creating a responsive and clean user experience. The project uses Aceternity UI components along with custom CSS styling to create scalable and maintainable interfaces.

---

🚀 Features

* Responsive modern UI
* Built with Next.js and TypeScript
* Reusable component-based architecture
* Clean and maintainable folder structure
* Optimized frontend performance
* Mobile-friendly design

---

🛠️ Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Aceternity UI
